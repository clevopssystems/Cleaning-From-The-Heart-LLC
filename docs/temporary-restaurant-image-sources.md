# Temporary Restaurant Image Sources

**Development reference only. This file is not published on the website and is not linked from any page.**

Every image listed here is a **temporary royalty-free stock photograph** used to show the intended
visual direction on the two restaurant service pages. None of it is Cleaning From The Heart work,
none of it is a Seattle client property, and none of it is presented on the site as either. All of it
should be replaced with original Cleaning From The Heart photography when that becomes available.

The pages carry no captions or alt text claiming these are company jobs. Where a caption sits next to
a stock photo in the results area, it is explicitly labelled a "Reference image", and the real Results
Gallery CTA (`/gallery`) is kept visually and textually separate.

## Replacement checklist

When original Cleaning From The Heart photography is available, the twelve files above can be replaced
in place — the page components reference them only by path, so no code changes are needed as long as
the new files keep the same filenames and roughly the same aspect ratios:

| Aspect | Files |
| --- | --- |
| 4:3 | both hero images |
| 4:5 | `commercial-kitchen-prep-surfaces.webp` |
| 16:9 / 16:10 | `restaurant-dining-area-cleaning.webp`, `commercial-kitchen-floor-and-equipment.webp`, `restaurant-front-of-house-bar.webp`, `commercial-kitchen-comparison.webp` |
| 3:2 | the remaining four |

If aspect ratios change, update the `width`/`height`/`aspect` props at the matching call site in
`app/services/restaurant-cleaning/page.tsx` or `app/services/restaurant-kitchen-cleaning/page.tsx`.

Highest-value shots to capture first, in priority order:

1. A real Seattle dining room, worked and reset — replaces both `restaurant-cleaning-hero.webp` and
   `restaurant-dining-room.webp`, the two largest images on the front-of-house page.
2. A real commercial kitchen the company services, shot after a visit — replaces
   `restaurant-kitchen-cleaning-hero.webp` and removes the equipment-nameplate issue noted above.
3. A crew member working a dining room or kitchen floor after close — replaces
   `restaurant-dining-area-cleaning.webp`, the only image on either page showing people, and the one
   most likely to be misread as company staff.
4. A bar / service counter and a prep-surface detail — replaces the two comparison-panel images, which
   is where the front-of-house vs. back-of-house distinction is carried visually.
5. Once real work photos exist, both "reference image" captions in the results sections can be dropped
   and those blocks can point at the gallery as genuine proof.
