# Temporary Post-Construction & Renovation Image Sources

**Development reference only. This file is not published on the website and is not linked from any page.**

Every image listed here is a **temporary royalty-free stock photograph** used to establish the visual
direction on `/services/post-construction-renovation-cleanup`. None of it is Cleaning From The Heart
work, none of it is a Seattle client property, and none of it is presented on the site as either. All
of it should be replaced with original Cleaning From The Heart photography once construction cleanup
jobs have been photographed.

No before/after pair is shown on the page, because no genuine post-construction before/after
photography exists. Every caption beside a stock photo on the page begins with **"Reference image"**,
and the real Results Gallery CTA (`/gallery`) is kept visually and textually separate from them.
